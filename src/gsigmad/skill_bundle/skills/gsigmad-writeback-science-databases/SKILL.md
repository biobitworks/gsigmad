# gsigmad-writeback-science-databases

Write verified publication/entity/source records to science databases only
after JSON import, SeedGraph Merkle ingest, destination routing, and explicit
operator approval.

This skill is blocked by default. It never treats an absent adapter as success.

## Supported Destinations

- `prothub`
- `proatlas`
- `seedgraph_kg`
- `triage_sqlite`
- `research_hub`
- other explicitly configured science-database adapters

## Preconditions

- destination queue generated by `gsigmad-route-publication-destinations`
- verified `publication.atomic.json` proof for every promoted package
- proof fields: `proof_id`, `source_seed_id`, `source_sha256`,
  `source_member_root`, `derived_asset_root`, `receipt_root`,
  `replay_fingerprint`
- row-level restricted data blocked or explicitly approved
- operator approval names exact destination(s)
- adapter status is `configured`

## Hard Halts

Halt with `SCIENCE_DATABASE_WRITEBACK_CUSTODY_VIOLATION` if:

- adapter status is missing or `not_configured`;
- Merkle proof is absent, blocked, or unverified;
- queue contains raw row-level restricted payloads;
- queue item lacks source hash, proof ID, or replay fingerprint;
- writeback would skip receipt generation;
- destination is not named in current operator approval.

## Receipt Requirement

Every attempted destination must emit a receipt or a blocked record:

```text
destination
adapter_status
payload_file
payload_count
source_seed_id
source_sha256
proof_id
replay_fingerprint
writeback_status
mutation_performed
live_writeback_performed
blocked_reason
receipt_path
created_at
```

## Report Back

- destinations requested
- destinations configured
- jobs written
- jobs blocked
- receipt paths
- adapters still `not_configured`
