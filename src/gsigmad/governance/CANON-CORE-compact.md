## Universal Invariants

### Invariant 1: No Fabricated Data, Claims, or Values
Every datum and claim must trace to a verifiable source; fabrication and undocumented parameter invention are prohibited.

### Invariant 2: Run-ID-Specific Result Artifacts
Every result artifact must be stamped with a unique run identifier; fixed-name overwritable outputs are prohibited.

### Invariant 3: Claim Classification Required
Every scientific claim must be tagged MEASURED, INFERRED, or HYPOTHESIS with documented justification before promotion.

### Invariant 4: Append-Only Change Logs
Corrections are made by appending new signed entries; editing or deleting prior governed records is a CANON violation.

### Invariant 5: Pre-Registration Before Execution for CONFIRMATORY Experiments
CONFIRMATORY experiments must lock H0, H1, test, alpha, and MESI in a committed document before data is loaded.

### Invariant 6: Effect Size and Confidence Interval Mandatory
Every statistical test must report an appropriate effect size measure and a 95% confidence interval alongside p-values.

### Invariant 7: Preserve Negative and Falsified Findings
Null results and disproven hypotheses must be documented with power analysis and registered in the negative results log.

### Invariant 8: Material Prompts Require Pre-Execution Red Team
Prompts that alter scientific conclusions, benchmark design, or KG state must have a committed red team review before execution.

### Invariant 9: Agent Provenance and Signature Required
Every governed document modification must carry a SIG-ID with the actual model identifier and a computed hash4.
