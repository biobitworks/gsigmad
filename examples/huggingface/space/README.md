# gsigmad Gate Trace Demo

This is a static Hugging Face Space template for showing the public-safe gate
trace boundary. Hugging Face Spaces read configuration from the YAML block in
the repository `README.md`; static Spaces use `sdk: static` and can serve an
`index.html` file directly.

The demo intentionally avoids model calls, private adapters, external
databases, and live writeback targets.
